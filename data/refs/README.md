# data/refs -- reference stopping-power data

Independent reference data used to validate the nuclear-stopping model
(`nuclear.py` / `nuclear_gk.py`). Not produced by this package.

- `Al_nuclear_zbl.dat` -- nuclear stopping cross section for protons in aluminum
  from the ZBL universal nuclear stopping (the basis of the NIST/ICRU-49 nuclear
  column), in `10^-15 eV cm^2/atom` vs energy per AMU (MeV). Two columns:
  `E/amu[MeV]  Sn`. Regenerated by `python nuc_test.py fig1` (see
  `zbl_nuclear()` there).

Add further reference tables here (e.g. PSTAR/ASTAR nuclear columns, published
WDM stopping points) as additional `<material>_<source>.dat` files with a header
line documenting the source and units.
